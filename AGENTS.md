# Entrega

Nada fica “pronto” só no código ou no localhost.

Antes de entregar qualquer mudança de UI, fluxo, bot ou painel:

1. Abrir o **URL de produção** (Worker no ar). Se ainda não houver produção, publicar primeiro.
2. Percorrer o fluxo como utilizador: login, páginas afectadas, estados vazios e erro.
3. **Tirar print** de cada ecrã relevante.
4. **Analisar** os prints: contraste, texto ilegível, ecrã preto, botões mortos, regressão.
5. Se falhar, corrigir e repetir. Só então marcar como finalizado.

Localhost serve para desenvolver. Produção + print + análise é o critério de pronto.
